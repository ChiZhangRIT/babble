# iPhone 床头模式验收

状态：**待真机测试**。自动化测试使用模拟麦克风、合成声音和注入的故障，不能据此认定整夜耗电、发热、真实梦话识别已经合格。

当前版本是网页 App：床头页需要保持前台、屏幕常亮。锁屏或切换 App 时暂停，是当前限制；应检查报告是否如实标出这段中断。原生后台录音不在本轮实现范围内。

## 准备

1. 先导出一份现有数据备份并保存到「文件」。测试记录使用「测试语音」等虚构内容。
2. 确认网站已发布新版。联网打开 App，在「设置 → 关于」记录实际版本；如提示有新版，关闭所有 Babble 窗口后重新打开，再核对版本。
3. 先下载床头模式需要的说话识别模型。记录手机型号、iOS 版本、剩余空间、是否接电、低电量模式、屏幕亮度和房间背景声。
4. 真录音和含个人信息的摘要只保留在自己的设备或私有备份中，不加入公开项目仓库。默认保持其他同域网页 App 关闭。

## 通过与阻塞项

- 必须通过：已有片段能保存和试听，重启能恢复；时间和中断报告真实；批量整理、备份和同步没有数据丢失或重复。
- 需要记录后再判断：耗电、发热、误报数量及低声语音捕捉。没有实测值前不标为通过，也不对外承诺准确率或续航。
- 当前限制：锁屏持续采集仍未实现。公开发布若宣传整夜锁屏录音，应先完成原生音频模块，并重新进行同样的中断、恢复和整夜验收。
